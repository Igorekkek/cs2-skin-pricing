# 04 · Какие признаки важны

**Вопрос.** На каких группах признаков держится точность и стоит ли оставлять новые поля?

**Признак** — одно число или категория, которую модель знает о лоте: float, название
скина, суммарная стоимость наклеек и так далее. Признаки объединены в группы.

* Группы по очереди убираются из стандартного набора, и для каждой измеряется, насколько
  хуже становится модель.
* Две **новые** группы взяты из полей ответа API, которые исходный парсер выбрасывал:
  `float_rank` (место float предмета в общем рейтинге CSFloat) и `pattern_extras`
  (доля синего и золотого у Case Hardened, процент Fade). Эти поля есть только у 2–3%
  продаж, поэтому их отдельно оценивают и на этих продажах.
* Две группы, которые *не должны* помогать честной модели: `lot_behavior` (число
  наблюдающих за лотом; оно записано уже после продажи, то есть это подглядывание в
  будущее) и `calendar` (час и день недели продажи).

**Метод.** CatBoost с настройками по умолчанию, обученный на 200 тысячах самых свежих
строк обучающей выборки. Исходное исследование показало, что решения о наборе признаков,
принятые на подвыборке, переносятся на полные данные, а решения о режиме обучения (скорость
обучения, фильтры строк) нет. Подвыборка позволяет сделать одиннадцать запусков за
разумное время. Оценка идёт на всём тесте.

**Запуск.** `python experiments/04_feature_ablation/run.py`

## Результат

**Сначала о шуме.** Одна и та же конфигурация с тремя разными случайными зёрнами дала
медианную ошибку 5,03%, 4,93% и 5,13% (средняя ошибка $1,48 / $1,40 / $1,54). Значит, на
этой подвыборке разница между одиночными запусками меньше ~0,1 п.п. по медианной ошибке
или ~$0,07 по средней — это шум.

| изменение (CatBoost, 200 тыс. свежих строк) | медианная ошибка | средняя ошибка | вывод |
|---|---|---|---|
| все стандартные группы (3 зерна) | 4,93–5,13% | $1,40–1,54 | точка отсчёта |
| − оценка CSFloat | 5,73% | $1,96 | необходима |
| − наклейки | 5,16% | $1,94 | необходимы для долларовой ошибки |
| − брелоки | 5,13% | $1,48 | на границе шума |
| − номер паттерна и раскраски | 5,04% | $1,48 | шум |
| − ранг float (новое) | 4,98% | $1,47 | шум |
| − blue gem / fade (новое) | 5,07% | $1,46 | в целом шум, но помогает «своим» продажам (ниже) |
| − история рынка | 4,96% | $1,40 | для CatBoost шум (перепроверено ниже) |
| + наблюдающие (после продажи) | 5,09% | $1,50 | не помогает |
| + час и день недели | 5,08% | $1,44 | не помогает |

**Новые поля на продажах, где они есть** (по 2,5 тысячи тестовых продаж). Данные blue gem /
fade снижают медианную ошибку на скинах Case Hardened и Fade с 8,40% до 7,88% (один запуск).
Ранг float не помогает: 17,2% против 17,5% и большая долларовая ошибка.

**История рынка на полных данных**, две модели:

| модель | с историей | без истории |
|---|---|---|
| CatBoost | 4,96%, $1,38 | 4,90%, $1,33 |
| HGB из scikit-learn + target encoding | **4,65%, $1,37** | 4,88%, $1,44 |

## Вывод

* Точность держится на оценке CSFloat и наклейках. Без оценки ошибка растёт на 0,7 п.п.,
  без наклеек долларовая ошибка вырастает на треть. Брелоки в целом на границе шума, но
  важны для тех 5% лотов, где они есть.
* `watchers` (число наблюдающих) входило в десятку важнейших признаков исходной модели.
  Когда есть остальные признаки, оно ничего не даёт, так что честная модель ничего не
  теряет без этого «послепродажного» поля. Признаки календаря подтверждают исходный вывод:
  эффекта нет.
* Признаки истории рынка (скользящие наценки скина, каждой наклейки и пары «скин +
  паттерн», посчитанные без подглядывания в будущее) дают модели scikit-learn 0,23 п.п. и
  $0,07, а CatBoost ничего. Вероятно, CatBoost и так собирает эту информацию своей
  статистикой по тем же категориям (это не проверялось). Без этих признаков модель
  scikit-learn идёт вровень с CatBoost (4,88% против 4,90%), то есть они объясняют всё её
  преимущество в эксперименте 02.
* Из двух полей, восстановленных из ответа API, данные blue gem / fade стоит оставить для
  скинов, где важен паттерн, а ранг float — нет.

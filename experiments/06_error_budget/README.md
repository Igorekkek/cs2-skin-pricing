# 06 · Где сосредоточена ошибка

**Вопросы.**

1. Какие лоты дают долларовую ошибку? Для этого доля продаж сравнивается с долей
   суммарной ошибки в долларах по стоимости наклеек, по цене и по наличию брелока.
2. Может ли модель оценить крафт, точный набор наклеек которого она никогда не видела?
3. Насколько модель близка к шуму самого рынка? Одинаковые обычные предметы (то же
   название, float в пределах 0,005), проданные в один день, всё равно продаются
   по-разному. Каждую такую продажу сравниваем с медианой *других* продаж из её группы и
   на тех же продажах оцениваем модель.

Используются прогнозы `premium_catboost` на тесте из эксперимента 02.

**Запуск.** `python experiments/06_error_budget/run.py`

## Результат

Числа для `premium_catboost` на тесте ([results.md](results.md)).

**1. Бюджет ошибки.** Лоты дороже $100 — это 4% продаж и 59% всей ошибки в долларах.
Крафты с наклейками дороже $100 — 0,8% продаж и 35% ошибки. Лоты с брелоком — 4,8% продаж
и 20% ошибки. А лоты дешевле $1 составляют 42% продаж и всего 1,2% ошибки.

**2. Незнакомые наборы наклеек.** У 42% крафтов в тесте такого набора наклеек в
обучении не было. При наклейках дешевле $500 медианная ошибка на них такая же, как на
знакомых наборах (например, при $5–20: 4,6% на новых против 5,2% на знакомых). Дороже
$500 немного хуже: 21,3% против 17,9%. Значит, модель оценивает крафт по его наклейкам, а
не запоминает конкретные сочетания.

**3. Шум рынка.** Для обычных предметов каждую продажу сравнили с медианой *других*
таких же продаж того же дня (то же название, float в пределах 0,005; 31 тысяча продаж).
Такое сравнение использует цены того же дня, которых модель знать не может, поэтому это
оптимистичная нижняя граница ошибки.

| цена | медиана продаж-«соседей» того же дня | модель |
|---|---|---|
| < $1 | 4,2% | 9,2% |
| $1–5 | 2,7% | 5,0% |
| $5–20 | 2,6% | 3,3% |
| $20–100 | 2,8% | 2,7% |
| > $100 | 2,7% | 2,2% |

## Вывод

Для предметов дороже $20 модель, которая видит только прошлое, так же точна, как знание
того, за сколько такие же предметы продаются сегодня. На дорогих обычных предметах
улучшать больше нечего. Запас остаётся в двух местах. Первое — дешёвые предметы
(до $5): их цены меняются целыми центами и за считанные дни. Второе — дорогие крафты,
на которые приходится треть долларовой ошибки.

Это уточняет вывод исходного отчёта о том, что модель уже упёрлась в шум рынка. Для
дорогих обычных предметов это верно, для дешёвого большинства нет.
